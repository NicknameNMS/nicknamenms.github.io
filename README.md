# Nicholas Tipton — Engineering Portfolio

This is a static GitHub Pages site. It has no external runtime dependencies;
the workflow publishes `index.html`, `images/`, and `Tipton-Resume.pdf`.

## Publish with GitHub Pages

1. Push this repository to GitHub. For a profile site, the repository must be
   named `<your-github-username>.github.io`.
2. In the repository, open **Settings → Pages** and set the source to
   **GitHub Actions**.
3. Push to `main`. The included workflow deploys the site automatically.
4. GitHub Pages will publish the site at `https://<your-github-username>.github.io/`.

The page uses relative paths for its local media and résumé, so they work from
the repository root.
