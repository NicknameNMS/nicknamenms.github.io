# Nicholas Tipton — Engineering Portfolio

This is a static GitHub Pages site. It has no build step or external runtime
dependencies; GitHub Pages serves the files directly from the repository root.

## Publish with GitHub Pages

1. Push this repository to GitHub. For a profile site, the repository must be
   named `<your-github-username>.github.io`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select
   `main` and `/(root)`, then save.
4. Push changes to `main`; GitHub Pages publishes them automatically.
5. GitHub Pages will publish the site at `https://<your-github-username>.github.io/`.

The page uses relative paths for its local media and résumé, so they work from
the repository root.
