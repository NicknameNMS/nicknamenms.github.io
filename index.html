Featured work: Texas Instruments

RF front-end characterization for a 16-bit, 1.5 GSPS RF sampling ADC, from first-principles noise model to measured hardware.

Application Engineering Intern

Texas Instruments, Dallas TX · May – Aug 2026

A high-speed differential ADC needs something to turn a single-ended signal into a differential one, and each usual choice gives something up. A balun is passive, so it adds no noise and keeps the full dynamic range, but it has no gain, blocks DC, and takes up board space. A single-ended-to-differential amplifier adds gain for better sensitivity, passes DC, and is compact, but its own noise raises the floor and eats into dynamic range. My project tested a way to get both: two amplifiers in parallel, feeding two ADC channels averaged in DSP, so the amplifiers' independent noise partly cancels while the gain and DC coupling stay.

I worked out the noise model by hand, predicted each configuration's noise floor, then built six front ends around the TRF1305C1 (a DC–7 GHz fully differential amplifier) and the ADC32RF72 (a 1.5 GSPS RF sampling ADC). I measured amplifier noise figure by Y-factor and gain methods on an R&S FSW, extracted S-parameters on a ZNB20 VNA, and wrote the Python that aligns, averages, and analyzes the ADC captures.

Step through the project, from the problem to the measured results

Differential ADC inputs reject common-mode and supply noise, allow 3 dB more input swing, and cancel even-order distortion. Getting a single-ended signal into one means choosing a front end, and each option trades sensitivity, dynamic range, and DC coupling against each other:

Correlated signals add in voltage

Vsum = V1 + V2 = 2·Vsignal

20·log(2) = 6 dB

Uncorrelated noise adds in power

Vn = √(Vn1² + Vn2²) = √2·Vn

20·log(√2) = 3 dB

Identical amplifiers, so

SNR gain = 6 dB − 3 dB = 3 dB

The scopes run that live: each amplifier adds its own random noise, and the summer doubles the signal while the independent noise only grows by √2.

The catch: the splitter

Splitting sin two ways halves the signal power in each branch:

10·log(½) = −3 dB SNR per channel

Net = −3 dB + 3 dB = 0 dB

On the bench, a splitter feeds both amplifiers, so the 3 dB only wins back what the splitter cost. In a real system the fix is to drop the splitter: put an antenna at each amplifier input and do the combining digitally. The signal still arrives correlated at both channels, the amplifier noise stays independent, and the full 3 dB is kept.

Why averaging helps: each amplifier's noise is independent, so the channels are RMS-averaged and the noise drops by √2, a 3 dB improvement over the single amplifier. Assumes a brick-wall anti-alias filter.

The takeaway: the single amplifier's noise is shared by both channels, and a balun adds none, so averaging should do nothing for either. Only the parallel amplifiers have independent front-end noise for averaging to cut. That noise is also 44% of each channel's total, so cutting it matters.

Conversions: PW = 10(PdBm − 30)/10, V = √(P·50 Ω), independent noise sources add as root-sum-square in power, and PdBFS = PdBm − 4.1 dBm full scale.

Six front ends, built and measured on the same ADC so every result is apples to apples. The amplifier paths are DC coupled; baluns can't pass DC.

  • Parallel amplifiers gave the best averaging gain, within 0.08 dB of the 3 dB NSD prediction. Their absolute floor came in 3 dB high because the DC–7 GHz amplifier's out-of-band noise folds back past the 1.5 GSPS Nyquist limit; an input filter fixes that.
  • Single amplifier and balun should show 0 dB from averaging, but did better because the two ADC channels, paths, and splitter aren't perfectly matched, so part of their noise is uncorrelated. The balun was also connected with lab splitters and cables rather than properly sized PCB parts. On a real board that leftover benefit shrinks, while the parallel amplifiers keep theirs.
